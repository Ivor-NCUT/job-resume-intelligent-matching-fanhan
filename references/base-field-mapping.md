# 飞书 Base 字段映射

默认 Base：`A80Xb9jOnaexcKswFkacPBoEnAf`（`泛函｜公司&职位&候选人`）。每次运行仍先用 URL 解析与字段读取核验实时结构。

## 候选人表

候选人表：`tbldGJk6awx45Chc`。

- `姓名 & 昵称`: 候选人姓名。
- `候选人职位类目`: 与 JD `职位分类` 做集合相交的候选池门控字段。
- `实习 & 正职`: 候选人当前寻找实习、正职，或两者都可。
- `候选人检索字段 JSON.文本`: OpenAPI 可读的首选简历 JSON。
- `候选人检索 JSON（Agent回填）`: 首选字段为空时的文本 JSON 回退。
- `候选人检索字段 JSON.附件`: 两个文本字段都不可用时的 JSON 附件回退。
- `简历`: 入选候选人的原始简历附件。
- `作品集/补充材料`: 其他证据附件。

`候选人检索字段 JSON` 是 Object 字段，当前 OpenAPI 返回 unsupported；不要把读不到该列误判为没有 JSON。

- `岗位名称`: 岗位名称；用于推断实习或正职。

- `岗位属性`: 全职、实习、线下、远程、高管等属性。
